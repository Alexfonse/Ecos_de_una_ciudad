# Ecos de una Ciudad

**Ecos de una Ciudad** es una plataforma web interactiva y transmedia que narra la historia de Bogotá a través de sus personajes, arquitectura y leyendas.

> **Nota:** Este proyecto ha sido refactorizado para utilizar **Módulos ES6**, lo que mejora el rendimiento y la organización del código.

## 🚀 Cómo Ejecutar

Debido al uso de módulos (`type="module"`), este proyecto requiere un servidor web local para funcionar correctamente (no se puede abrir directamente haciendo doble clic en `index.html`).

### Opciones Rápidas:

1.  **VS Code:** Instala la extensión "Live Server" y haz clic en "Go Live".
2.  **Node.js:** Ejecuta `npx serve .` en la terminal.
3.  **Python:** Ejecuta `python -m http.server` en la terminal.
